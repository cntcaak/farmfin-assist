## 📌 Overview

FarmFin Assist is an intelligent agri-credit decision support platform designed to simplify financial planning and loan accessibility for farmers.

The platform helps users evaluate financial health, understand loan affordability, discover government schemes, and generate reports for informed decision-making.

The objective is to reduce financial uncertainty and improve accessibility to agricultural financing.

---

## ✨ Features

### 💰 Financial Health Analysis
- Debt Service Coverage Ratio (DSCR) calculation
- Estimated credit scoring logic
- Financial risk assessment
- Loan affordability evaluation

### 🌐 Multilingual Support
- Support for 22+ Indian languages
- User-friendly localized experience
- Reduced language barriers

### 📊 Smart EMI Calculator
- Dynamic EMI calculation
- Principal vs interest visualization
- Loan repayment estimation

### 🌱 Crop Profitability Insights
- Crop profitability estimation
- Revenue analysis
- Financial forecasting support

### 🏛 Government Scheme Discovery
Direct access to agricultural support schemes including:

- PM-KISAN
- Agricultural Infrastructure Fund
- e-NAM
- Additional government initiatives

### 📄 Report Generation
- Downloadable PDF reports
- Financial summaries
- Loan planning reports

## 🚀 Installation

Clone repository:

```bash
git clone https://github.com/cntcaak/FarmFin-Assist.git

cd FarmFin-Assist
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶ Running the Application

Launch Streamlit:

```bash
streamlit run app.py
```

Open:

```text
http://localhost:8501
```
